# 首頁模塊 Builder Demo

這是一個純前端展示專案，用來和工程師溝通首頁 Section Builder 的後台邏輯。

## 功能

- 新增首頁模塊
- 刪除非固定模塊
- 已新增但暫不顯示
- 拖曳排序中間模塊
- 模塊類型下拉選單，選項內含用途說明
- 版型 tab 預覽，切換時先看版面差異
- 設定欄位直接填寫，欄位下方有用途說明
- 是否顯示頁面連結
- 右上角儲存後，前台預覽才套用草稿變更

## 使用方式

直接開啟 `index.html` 即可。

如果要用本機靜態伺服器展示，也可以在這個資料夾執行：

```bash
python -m http.server 8080
```

再開啟 `http://localhost:8080`。
